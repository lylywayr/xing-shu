# 星枢外部集成说明

## 通用 Provider

除 FreeLLMAPI 外，星枢只使用 OpenAI-compatible 标准接口：

- `GET <base>/models`
- `POST <base>/chat/completions`

Provider 地址和 Key 只能通过部署环境变量或受信任的部署配置注入。控制台不接受任意 URL，不扫描局域网，也不保存完整 Key。模型目录中的能力字段只有在上游明确提供并通过校验后才会采用，未知能力不会被推断为支持。

## FreeLLMAPI

FreeLLMAPI 是可选的外部本地集成，不是星枢内置 Provider。管理员需要在控制台执行显式只读探测和授权：

1. 未授权时不发起 FreeLLMAPI 探测、目录同步、额度读取或推理调用。
2. 授权只允许读取受信任配置下的健康、模型和脱敏额度事实。
3. “允许生产路由”是独立开关；接入但关闭生产路由时只观察，不进入实际候选。
4. 撤销授权会使外部模型退出候选，保留必要的历史治理状态但不再读取外部数据。

如需读取其本地额度，部署者必须自行提供只读数据目录并设置 `FREELLMAPI_DB_PATH`。星枢不修改外部代码、SQLite、WAL 或 SHM，不读取下游密钥、管理 Cookie、Prompt 或 Response。无法解析的预算标签保留原文并标记为部分可解释，不伪造绝对额度。

## 额度与告警语义

额度只接受可验证的上游事实，并区分 `available`、`unavailable`、`stale` 和 `unauthorized`。接口不存在、认证失败、字段不足或上游超时都不会被转换成 0。不同单位（请求数、Token、金额、时间窗口）不会相加；共享池不会复制成每个模型的独立余额。

默认 Compose 不启用外部额度采集或消息告警。若未来部署自定义采集器，必须使用只读接口、超时、响应大小限制、重试上限和脱敏错误；采集器的凭证不得写入仓库或运行日志。

## 网络与隐私边界

- 不接受用户输入的任意外部 URL，避免 SSRF。
- 禁止不受控重定向携带 Authorization 到其他主机。
- 上游响应按大小和结构校验，失败保留 last-known-good 状态。
- 审计只记录 Provider、模型、状态、耗时和摘要错误，不记录完整请求内容、响应或密钥。
- 星枢自身健康不因可选外部集成不可用而降级；仅相关 Provider 候选被禁用或标记不可用。
